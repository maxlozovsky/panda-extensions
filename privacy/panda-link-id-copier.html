Panda Link ID Copier — Privacy Policy

Last updated: September 17, 2026.

What the extension handles

Panda Link ID Copier processes the URL of a hyperlink only when you explicitly invoke its context-menu copy action. It may extract an identifier from that URL and copy the identifier, or the URL itself, to your clipboard.

If you enable history, the extension may store the copied link URL, domain, extracted identifier, recognized site/type metadata, and date locally in your browser. History is disabled by default.

Local data

The extension stores its settings, optional history, selected interface language, interface preferences, a lifetime count of successful copy actions, and a cached copy of the public Panda extensions catalog in chrome.storage.local. This data is stored on your device and is not synchronized by the extension.

Network requests

The extension fetches a public static catalog from https://maxlozovsky.github.io/panda-extensions/catalog.json and may display images from the same site's /panda-extensions/assets/ directory. These requests do not include copied URLs, extracted IDs, history, settings, or other extension user data, and the catalog request is made without credentials.

The extension does not use analytics, advertising, telemetry, user accounts, or a developer-operated backend. Standard network metadata may be processed by the GitHub Pages hosting infrastructure when public catalog files are requested, according to GitHub's own policies.

Sharing and sale of data

Copied URLs, extracted IDs, local history, settings, and usage counters are not sent to the developer or shared with third parties. They are not sold, used for advertising, used for purposes unrelated to the extension's core functionality, or used to determine creditworthiness or for lending.

Retention and deletion

History remains in local extension storage until you clear it in the extension or uninstall the extension. Settings and other local extension data remain until changed or until the extension is uninstalled. The extension has no server-side copy of this data for the developer to delete.

Chrome Web Store Limited Use

The use of information received through Chrome extension APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact
