Panda Link ID Copier – Privacy Policy

Last updated: September 17, 2026.

What the extension handles

Panda Link ID Copier processes the URL of a hyperlink only when you explicitly invoke its context-menu copy action. It may extract an identifier from that URL and copy the identifier, or the URL itself, to your clipboard.

If you enable history, the extension may store the copied link URL, domain, extracted identifier, recognized site/type metadata, and date locally in your browser. History is disabled by default.

Local data

The extension stores its settings, optional history, selected interface language, interface preferences, a lifetime count of successful copy actions, and a cached copy of the public Panda extensions catalog in chrome.storage.local. This data is stored on your device and is not synchronized by the extension.

Network requests

The extension fetches a public static catalog from https://maxlozovsky.github.io/panda-extensions/catalog.json and may display images from the same site's /panda-extensions/assets/ directory. These requests do not include copied URLs, extracted IDs, history, settings, or other extension user data, and the catalog request is made without credentials.

The extension does not use analytics, advertising, telemetry, user accounts, or a developer-operated backend. Standard network metadata may be processed by the GitHub Pages hosting infrastructure when public catalog files are requested, according to GitHub's own policies.

Sharing and sale of data

Copied URLs, extracted IDs, local history, settings, and usage counters are not sent to the developer or shared with third parties. They are not sold, used for advertising, used for purposes unrelated to the extension's core functionality, or used to determine creditworthiness or for lending.

Retention and deletion

History remains in local extension storage until you clear it in the extension or uninstall the extension. Settings and other local extension data remain until changed or until the extension is uninstalled. The extension has no server-side copy of this data for the developer to delete.

Chrome Web Store Limited Use

The use of information received through Chrome extension APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

For questions about this policy, contact the developer through GitHub.

Panda Link ID Copier – Политика конфиденциальности

Последнее обновление: 17 сентября 2026 года.

Какие данные обрабатывает расширение

Panda Link ID Copier обрабатывает URL ссылки только тогда, когда вы явно вызываете для неё действие копирования через контекстное меню. Расширение может извлечь идентификатор из этого URL и скопировать идентификатор либо сам URL в буфер обмена.

Если вы включите историю, расширение может локально сохранять в браузере URL скопированной ссылки, домен, извлечённый идентификатор, распознанный сайт и тип, а также дату. По умолчанию история выключена.

Локальные данные

Расширение хранит настройки, необязательную историю, выбранный язык интерфейса, настройки интерфейса, общий счётчик успешных копирований и кэш публичного каталога расширений Panda в chrome.storage.local. Эти данные хранятся на вашем устройстве и не синхронизируются расширением.

Сетевые запросы

Расширение загружает публичный статический каталог с https://maxlozovsky.github.io/panda-extensions/catalog.json и может показывать изображения из каталога /panda-extensions/assets/ на том же сайте. В эти запросы не передаются скопированные URL, извлечённые ID, история, настройки или другие пользовательские данные расширения; запрос каталога выполняется без учётных данных.

Расширение не использует аналитику, рекламу, телеметрию, пользовательские аккаунты или сервер разработчика. При запросе публичных файлов каталога инфраструктура GitHub Pages может обрабатывать стандартные сетевые метаданные в соответствии с политиками GitHub.

Передача и продажа данных

Скопированные URL, извлечённые ID, локальная история, настройки и счётчики использования не отправляются разработчику и не передаются третьим лицам. Они не продаются, не используются для рекламы или целей, не связанных с основной функцией расширения, и не используются для определения кредитоспособности или выдачи кредитов.

Хранение и удаление

История остаётся в локальном хранилище расширения, пока вы не очистите её в интерфейсе или не удалите расширение. Настройки и другие локальные данные сохраняются, пока вы их не измените или не удалите расширение. На сервере разработчика копии этих данных нет.

Ограниченное использование Chrome Web Store

Использование информации, полученной через API расширений Chrome, соответствует политике Chrome Web Store в отношении пользовательских данных, включая требования Limited Use.
